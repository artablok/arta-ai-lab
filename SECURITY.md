# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities privately to support@artablockchain.in.
Do not open public issues for security problems.

## Scope

- This repository contains documentation only (no source code, no deployment data).
- The underlying Arta AI Team system is private infrastructure operated by
  ArtaBlockchain Team.

## Responsible Disclosure

We ask reporters to avoid accessing, modifying or disrupting any systems, and to
give the team reasonable time to address confirmed issues before any public disclosure.

## Confidentiality Notice

Server addresses, credentials, internal instructions, personal data and confidential
business data must not be committed to this repository. Suspected leaks of such
material should be reported immediately to support@artablockchain.in.
